Backend developer focused on **Python**, **REST API design**, and **distributed systems**. I build services applying **Clean Architecture, DDD, and TDD**, tested against real PostgreSQL in CI — from auth-heavy modular monoliths to **event-driven microservices** with RabbitMQ (idempotency, dead-letter queues, eventual consistency, end-to-end observability).
